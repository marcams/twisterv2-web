# TwisterV2 Web

Aplicação web para modelagem paramétrica, visualização 3D e exportação de luminárias Twister.

## Executar

Abra `index.html` em um navegador moderno com suporte a WebGL. O projeto é distribuído como uma página HTML autocontida.
